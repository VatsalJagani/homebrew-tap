# Homebrew Tap

Custom Homebrew formulae by [vjagani](https://github.com/vjagani).

## Installation

```bash
brew tap VatsalJagani/tap
```

## Available Formulae

| Formula | Description | Install |
|---------|-------------|---------|
| [disktree](https://github.com/VatsalJagani/mac-disktree) | Drill-down storage inspector for macOS | `brew install VatsalJagani/tap/disktree` |

## Usage

After tapping, install any formula:

```bash
brew install disktree
```

To update:

```bash
brew update
brew upgrade disktree
```

## How It Works

Formulae in this tap are updated automatically via GitHub Actions when new versions are released in their source repositories.
